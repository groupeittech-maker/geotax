# Guide : Comment Scanner un QR Code avec un Téléphone

## 📱 Méthode 1 : Scan Direct avec la Caméra (Recommandé)

### Sur Android et iPhone

1. **Ouvrir la page de scan**
   - Accéder à `http://votre-serveur.com/scan` sur votre navigateur mobile
   - Ou cliquer sur "Scanner QR Code" dans le menu

2. **Activer le scan caméra**
   - Cliquer sur le bouton **"📷 Scanner avec la Caméra"**
   - Autoriser l'accès à la caméra lorsque le navigateur le demande

3. **Scanner le QR code**
   - Pointer la caméra vers le QR code de la boutique
   - **Pas besoin de prendre une photo** - le scan est automatique en temps réel
   - Le système détecte automatiquement le QR code et affiche le résultat

4. **Voir le résultat**
   - Le statut de paiement s'affiche immédiatement
   - ✅ **PAYÉ** = La boutique a payé ce mois-ci
   - ❌ **NON PAYÉ** = La boutique n'a pas payé ce mois-ci

### Permissions Nécessaires

- **Android Chrome/Edge** : Autoriser l'accès à la caméra
- **iPhone Safari** : Autoriser l'accès à la caméra
- **Firefox Mobile** : Autoriser l'accès à la caméra

## ⌨️ Méthode 2 : Saisie Manuelle

Si la caméra ne fonctionne pas ou si vous préférez saisir manuellement :

1. Cliquer sur **"⌨️ Saisir Manuellement"**
2. Entrer le code de la boutique (ex: `BOUTIQUE-57891`)
3. Cliquer sur **"🔍 Vérifier"**
4. Le résultat s'affiche immédiatement

## 🔧 Dépannage

### La caméra ne démarre pas

**Solutions :**
- Vérifier que vous avez autorisé l'accès à la caméra dans les paramètres du navigateur
- Essayer avec un autre navigateur (Chrome, Firefox, Edge)
- Utiliser la saisie manuelle à la place

### Le QR code n'est pas détecté

**Solutions :**
- S'assurer que le QR code est bien visible et éclairé
- Approcher ou éloigner la caméra pour trouver la bonne distance
- Nettoyer l'objectif de la caméra
- Utiliser la saisie manuelle si nécessaire

### Erreur "Boutique non trouvée"

**Causes possibles :**
- Le code QR est incorrect ou endommagé
- La boutique n'existe pas dans la base de données
- Le code a été mal saisi

**Solutions :**
- Vérifier que le QR code est celui de la bonne boutique
- Demander au commerçant de vérifier son QR code
- Contacter l'administrateur si le problème persiste

Si le téléphone ne supporte pas le scan caméra :
1. Utiliser la **saisie manuelle**
2. Entrer le code boutique affiché sur le QR code
3. Ou utiliser une application de scan QR code tierce

## 💡 Conseils pour les Contrôleurs

1. **Avant de partir sur le terrain**
   - Tester le scan sur votre téléphone
   - Vérifier que la caméra fonctionne
   - S'assurer d'avoir une connexion internet

2. **Pendant le contrôle**
   - Scanner le QR code de la boutique
   - Vérifier immédiatement le statut
   - Prendre une capture d'écran si nécessaire

3. **En cas de problème de connexion**
   - Utiliser la saisie manuelle
   - Noter le code boutique
   - Vérifier plus tard quand la connexion est rétablie

## 🔒 Sécurité et Confidentialité

- Le scan QR code ne stocke aucune information sur votre téléphone
- Les données sont vérifiées en temps réel depuis le serveur
- Aucune photo n'est prise ou sauvegardée
- L'accès à la caméra est uniquement utilisé pour le scan

## 📞 Support

En cas de problème persistant :
1. Vérifier la connexion internet
2. Essayer avec un autre navigateur
3. Utiliser la saisie manuelle
4. Contacter l'administrateur du système

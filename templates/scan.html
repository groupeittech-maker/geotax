Vérification rapide du statut de paiement sur le terrain

Scanner le QR code d'un POI

Caméra indisponible en HTTP

Les navigateurs n'autorisent la caméra que sur une connexion sécurisée (HTTPS) ou en local. Utilisez la saisie manuelle du code POI, ou configurez HTTPS sur le serveur.

Instructions

📱 Pour les Contrôleurs

  1. Méthode 1 - Scan Caméra (HTTPS requis) :
    • Cliquer sur "📷 Scanner avec la Caméra"
    • Autoriser l'accès à la caméra si demandé
    • Pointer la caméra vers le QR code du POI
    • Le scan est automatique - pas besoin de prendre une photo!
  2. Méthode 2 - Saisie Manuelle:
    • Cliquer sur "⌨️ Saisir Manuellement"
    • Entrer le code du POI
    • Cliquer sur "🔍 Vérifier"
  3. Le statut de paiement s'affiche immédiatement: ✅ PAYÉ ou ❌ NON PAYÉ

💳 Pour les Contribuables

  1. Via USSD : composez le code annoncé par la mairie, puis le code POI, puis le montant (format affiché après connexion).
  2. Via Mobile Money : indiquez le code POI en référence
  3. Le paiement est automatiquement enregistré
  4. Conservez votre QR code pour les contrôles
